# Claude vs Argon

Слепое сравнение сайтов, которые Claude Opus 5.5 и Argon 4 сделали по одинаковым промптам.

Сначала посетитель проходит тест: в каждом раунде по очереди смотрит сайт A и сайт B и угадывает, какой сделал Claude. После этого можно свободно переключаться между всеми версиями.

## Как добавить сайт

1. Положите html-файл в `sites/` под нейтральным именем (например, `sites/p4n8.html`), чтобы URL не выдавал модель.
2. Пропишите путь в `config.js` в нужном раунде вместо `null`.
3. Запушьте в `main` — GitHub Actions сам выложит сайт на Pages.

Сами сайты не редактируются: каждый открывается целиком во фрейме под панелью переключения.

## Горячие клавиши

- `H` — скрыть или показать панель
- `1` / `2` (или `A` / `B`) — переключить сайт в тесте
- `1`–`4` — переключить версию в свободном режиме

## Локальный запуск

```bash
python -m http.server 8000
```
